# Workout Tracker CLI

A simple command-line Python application for recording and managing workout records.

## Features

- Add workout records
- Validate workout information
- Display all workouts
- Calculate workout statistics
- Search workouts by exercise name
- Case-insensitive search
- Handle invalid menu input

## Technologies

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Exception handling

## How to Run

Run the following command:

```bash
python workout_tracker.py
